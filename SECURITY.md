# Security policy

## Supported version

Security fixes target the latest commit on the default branch. Older tags are not maintained separately.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential.

Use the repository's [private vulnerability report](https://github.com/agent-dev-thai/fake-gacha/security/advisories/new). If that option is unavailable, contact an Agent Dev Thai organization owner privately through GitHub and include:

- the affected route or file;
- reproducible steps;
- impact and required preconditions;
- a suggested fix, if known.

Please avoid accessing data that is not yours, disrupting the public deployment, or publishing details before maintainers have had a reasonable chance to investigate and release a fix.
